\section{Oracle Policy Feature Definitions}

The outer feature vector is
\begin{equation}
\begin{aligned}
\bphi_{\mathrm{out}}(v)=(&1,d(v),e_f(v),e_X(v),e_A(v),\\
&\hat n_T,\hat n_{\CNOT},\hat n_g,\hat D,\hat n_{\mathrm{macro}},\\
&\hat p,\ind[r_{\mathrm{last}}=X],\ind[r_{\mathrm{last}}=\CNOT],\\
&\ind[r_{\mathrm{last}}=\operatorname{TOF}],z_0(v))^\mathsf T.
\end{aligned}
\end{equation}
Here $d$ is exact mapping distance; $e_f,e_X,e_A$ are normalized flag, data, and workspace mismatch; the hatted quantities are resource fractions; $\hat p$ is the pending-token fraction; and $z_0$ is the fraction of zero literals of a uniquely marked input that have been complemented in the current exact mapping.

For macro $m$, the inner context is
\begin{equation}
\begin{aligned}
\bz(v,m)=(&1,d,d',d-d',e_f',e_X',e_A',\\
&c_g,c_T,c_{\CNOT},\ind[t(m)=f],\ind[t(m)\in A],\\
&z_X,z_C,z_{\mathrm{overlap}})^\mathsf T.
\end{aligned}
\end{equation}
The primed errors are computed after the exact proposed macro; $c_g,c_T,c_{\CNOT}$ are normalized native lowering costs; $z_X$ identifies an $X$ on a required zero literal; $z_C$ records whether the controls are active in the current image of a uniquely marked input; and $z_{\mathrm{overlap}}$ measures operand overlap with the previous macro.

\section{Discovered BNN Evaluator}

With data qubits $q_0=x_1$, $q_1=x_2$, $q_2=x_3$, flag $q_3=f$, and clean work $q_4=a$, the discovered evaluator is
\begin{align}
&\operatorname{TOF}_{q_0,q_1\rightarrow q_4},
\quad \CNOT_{q_0\rightarrow q_4},
\quad \CNOT_{q_4\rightarrow q_3},\nonumber\\
&\operatorname{TOF}_{q_2,q_4\rightarrow q_3},
\quad \CNOT_{q_0\rightarrow q_4},
\quad \operatorname{TOF}_{q_0,q_1\rightarrow q_4}.
\end{align}
For all Boolean inputs, the work trajectory is
\begin{equation}
a:0\rightarrow x_1x_2\rightarrow x_1\bar x_2
\rightarrow x_1\bar x_2\rightarrow x_1x_2\rightarrow0,
\end{equation}
while
\begin{equation}
f:0\rightarrow x_1\bar x_2
\rightarrow x_1\bar x_2\bar x_3.
\end{equation}
The native 98-gate phase-oracle witness is distributed in
\begin{verbatim}
data/oracle_result.json
\end{verbatim}
and in the repository experiment directory.  The article does not typeset all 98 lines because the exact machine-readable witness is the authoritative record.

\section{Restricted QFT-3 Qualification}

The restricted QFT-3 macro plan is
\begin{equation}
H_{q_2};\;\operatorname{CS}_{q_1,q_2};\;
\operatorname{CT}^{(a)}_{q_0,q_2};\;H_{q_1};\;
\operatorname{CS}_{q_0,q_1};\;H_{q_0};\;
\operatorname{SWAP}_{q_0,q_2}.
\end{equation}
Controlled-$S$ is lowered as
\begin{equation}
T_cT_t\CNOT_{c\to t}T_t^\dagger\CNOT_{c\to t}.
\end{equation}
Controlled-$T$ uses a certified relative-phase AND computation $R$, a $T$ on clean workspace, and the exact inverse $R^\dagger$:
\begin{equation}
R\;T_a\;R^\dagger.
\end{equation}
The input-dependent phase of $R$ cancels against that of $R^\dagger$.  The resulting native circuit has 35 gates, 15 $T/T^\dagger$ gates, 13 CNOTs, and depth 26.  This construction is restricted because the QFT block structure is supplied.  The generic unrestricted native search remains a separate negative bounded result.

\section{Reproduction Commands}

Install and run the complete regression suite:
\begin{verbatim}
python -m pip install -e '.[dev]'
python -m compileall -q hybrid_qcs tests
python -m pytest -q
\end{verbatim}

Generate the BNN verification oracle and all machine-readable artifacts:
\begin{verbatim}
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
hybrid-qcs-oracle \
  --output-dir outputs/bnn-oracle \
  --timing-repeats 5
\end{verbatim}

Run the restricted QFT-3 generator:
\begin{verbatim}
hybrid-qcs-qft3 \
  --output outputs/qft3-guided/result.json
\end{verbatim}

Build this article:
\begin{verbatim}
latexmk -pdf -interaction=nonstopmode \
  -halt-on-error main.tex
\end{verbatim}
