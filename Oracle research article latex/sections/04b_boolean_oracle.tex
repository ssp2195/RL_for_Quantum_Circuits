\section{Specification-Level Boolean Oracle Synthesis}
\label{sec:boolean-oracle}

\subsection{Boolean specification and reversible evaluator}

Let
\begin{equation}
g:\{0,1\}^{n}\rightarrow\{0,1\}
\end{equation}
be supplied by its exact truth table
\begin{equation}
\TT(g)=(g(0),g(1),\ldots,g(2^n-1)).
\label{eq:truth-table}
\end{equation}
The current implementation admits $1\leq n\leq3$.  The physical register contains read-only data wires $X=(x_1,\ldots,x_n)$, one predicate flag $f$, and a fixed clean workspace $A$.  The evaluator target is
\begin{equation}
\boxed{
U_g:\lvert x\rangle_X\lvert y\rangle_f\lvert0^a\rangle_A
\mapsto
\lvert x\rangle_X\lvert y\oplus g(x)\rangle_f\lvert0^a\rangle_A.
}
\label{eq:oracle-evaluator}
\end{equation}
During search it is sufficient to represent the action on the promised columns with $y=0$ and $A=0^a$, because the final phase construction uses exactly that input.  The native replay and final exact isometry certification nevertheless verify the complete declared contract.

For each data basis index $j$, let $\iota(j)$ be its physical-register embedding with flag and workspace zero.  A reversible macro prefix $v$ induces the ordered mapping
\begin{equation}
M_v=\bigl(F_v(\iota(0)),\ldots,F_v(\iota(2^n-1))\bigr),
\label{eq:mapping-key}
\end{equation}
where $F_v$ is the exact computational-basis permutation implemented by the prefix.  The target mapping is
\begin{equation}
M_\star(j)=\iota(j)\oplus g(j)2^{q_f}.
\label{eq:target-mapping}
\end{equation}
Equality of $M_v$ is exact integer equality; no floating-point hash is involved.

\subsection{Target-independent reversible macro grammar}

The evaluator search uses the universal reversible grammar
\begin{equation}
\cG_{\mathrm{rev}}
=\{X_q,\CNOT_{c\rightarrow t},\operatorname{TOF}_{c_0,c_1\rightarrow t}\}.
\label{eq:nct-grammar}
\end{equation}
Data wires may be complemented by $X$ to expose negative literals, but the target of CNOT or Toffoli is restricted to the flag or workspace.  This prevents the search from irreversibly overwriting an input bit while still permitting temporary data complementation.  The grammar depends only on the register layout; it is independent of the target truth table.

Every macro has an exact, fixed lowering to \eqref{eq:gate-library}.  CNOT is already native.  The implementation uses
\begin{equation}
X_q=H_qS_qS_qH_q
\end{equation}
and an independently tested exact 15-gate Clifford+$T$ Toffoli decomposition.  Hence the macro-level resource transition is computed from the actual native $T/T^\dagger$ count, CNOT count, total gate count, and per-wire depth, not from an abstract unit-cost model.

\subsection{Contract-relative canonicalization and Pareto pruning}

At the evaluator-search layer, $M_v$ is a complete semantic description of the prefix on the promised input domain.  The archive therefore uses
\begin{equation}
\kappa_{\mathrm{map}}(v)=M_v.
\label{eq:mapping-canonical-key}
\end{equation}
This key is stronger for the restricted Boolean task than the full-register Clifford+$T$ key: it merges physical macro prefixes that have the same continuation-relevant action on every allowed input, even if their behavior on invalid workspace inputs differs.

The resource vector is
\begin{equation}
\brho_{\mathrm{rev}}(v)=
\bigl(n_T,n_{\CNOT},n_g,d_0,\ldots,d_{N-1},n_{\mathrm{macro}}\bigr),
\label{eq:macro-resources}
\end{equation}
where the first three and the wire-depth coordinates are computed after exact native lowering of each macro.  For a fixed mapping key, the archive retains the componentwise Pareto antichain.  A record with no worse native resources can simulate every common future macro suffix available from a dominated record.

The second canonicalization layer operates after a macro witness has been found.  Its native gates are applied through the ordinary hybrid state, and the strengthened tableau--rotation canonicalizer in Section~\ref{sec:canonicalization} handles Clifford-valued rotation extraction and projective duplicate identity.  The two semantic layers have different purposes:
\begin{equation}
\begin{aligned}
\kappa_{\mathrm{map}}&:\ \text{exact Boolean evaluator search},\\
\kappa_{\mathrm{full}}&:\ \text{native Clifford+$T$ execution and pruning}.
\end{aligned}
\end{equation}

\subsection{Universal phase-oracle assembly}

After independent evaluator certification, the exact phase oracle is
\begin{equation}
\boxed{
O_g=U_g^\dagger Z_f U_g.
}
\label{eq:oracle-phase-wrapper}
\end{equation}
For every $x$,
\begin{equation}
\begin{aligned}
\lvert x,0,0^a\rangle
&\xmapsto{U_g}\lvert x,g(x),0^a\rangle\\
&\xmapsto{Z_f}(-1)^{g(x)}\lvert x,g(x),0^a\rangle\\
&\xmapsto{U_g^\dagger}(-1)^{g(x)}\lvert x,0,0^a\rangle.
\end{aligned}
\end{equation}
The flag and workspace therefore return clean.  Exact-phase mode is used because the phase pattern is the intended logical action, not an irrelevant scalar of a subroutine.

\subsection{The BNN verification predicate}

The concrete source experiment defines a Hamming-ball verification problem with the unique violating input $100$.  We adopt the exact diagonal extension
\begin{equation}
g(x_1,x_2,x_3)=x_1\bar x_2\bar x_3,
\qquad
O_g=I-2\lvert100\rangle\!\langle100\rvert.
\label{eq:bnn-predicate}
\end{equation}
The hierarchy is given the eight Boolean values in \eqref{eq:truth-table} and the generic grammar \eqref{eq:nct-grammar}.  It is not given the six operations in Fig.~\ref{fig:found-evaluator}.

The discovered evaluator can be checked symbolically.  With $a=f=0$ initially, the six updates are
\begin{align}
a&\leftarrow x_1x_2,\\
a&\leftarrow x_1x_2\oplus x_1=x_1\bar x_2,\\
f&\leftarrow x_1\bar x_2,\\
f&\leftarrow x_1\bar x_2\oplus x_3x_1\bar x_2
=x_1\bar x_2\bar x_3,\\
a&\leftarrow x_1x_2,\\
a&\leftarrow0.
\end{align}
Thus the output flag is exactly $g(x)$ and the workspace is restored for every input, before the native circuit is even passed to the independent quantum certifier.
